# Words Game

Мобильная party-игра, в которой участники загадывают друг другу слова по замкнутому кругу, объясняют их вживую и отмечают угадывание на телефоне. Победитель определяется по порядку угадывания.

> **Статус:** требования и архитектура MVP согласованы. Реализация ещё не начата; команды из документации являются контрактом для будущего приложения, а не описанием уже работающего проекта.

## MVP

- создание комнаты и вход по шестисимвольному коду;
- гостевой вход по имени без регистрации;
- восстановление игрока на том же устройстве через защищённую cookie;
- готовность участников и запуск админом;
- распределение 3–12 игроков в один замкнутый круг;
- необязательное скрытие имени адресата на этапе ввода слова;
- персональные подсказки без раскрытия собственного слова;
- места и очки по порядку угадывания;
- досрочное завершение админом;
- обновление состояния через SSE.

Архитектура выделяет общий каркас комнат и отдельные игровые модули. Первая игра имеет тип `WORD_CHAIN`; следующие игры должны добавляться без изменения гостевых сессий, участников и механизма комнат.

## Технологии

- Next.js App Router и TypeScript;
- PostgreSQL и Prisma;
- Bun для зависимостей, скриптов и тестов;
- shadcn/ui и Tailwind CSS;
- `iron-session` для гостевых сессий;
- Server-Sent Events для серверных уведомлений.
