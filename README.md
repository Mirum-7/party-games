# Words Game

Мобильная party-игра, в которой участники загадывают друг другу слова по замкнутому кругу, объясняют их вживую и отмечают угадывание на телефоне. Победитель определяется по порядку угадывания.

> **Статус:** MVP WORD_CHAIN реализован: комнаты с шестисимвольным кодом, гостевые сессии через защищённую cookie, готовность и запуск админом, распределение 3–12 игроков в один замкнутый круг, ввод слов с необязательным скрытием адресата, персональные подсказки без раскрытия собственного слова, угадывание с местами и очками, досрочное завершение и синхронизация через SSE. Команды ниже рабочие; окружение и обязательные проверки описаны в [docs/development.md](docs/development.md).

## MVP

- создание комнаты и вход по шестисимвольному коду;
- гостевой вход по имени без регистрации;
- восстановление игрока на том же устройстве через защищённую cookie;
- готовность участников и запуск админом;
- распределение 3–12 игроков в один замкнутый круг;
- необязательное скрытие имени адресата на этапе ввода слова;
- персональные подсказки без раскрытия собственного слова;
- места и очки по порядку угадывания;
- досрочное завершение админом;
- обновление состояния через SSE.

Архитектура выделяет общий каркас комнат и отдельные игровые модули. Первая игра имеет тип `WORD_CHAIN`; следующие игры должны добавляться без изменения гостевых сессий, участников и механизма комнат.

## Технологии

- Next.js App Router и TypeScript;
- PostgreSQL и Prisma;
- Bun для зависимостей, скриптов и тестов;
- shadcn/ui и Tailwind CSS;
- `iron-session` для гостевых сессий;
- Server-Sent Events для серверных уведомлений.

## Быстрый старт

```bash
bun install
# Одноразовая локальная PostgreSQL для разработки и тестов (порт 127.0.0.1:55432):
docker run --name words-game-mvp-db -e POSTGRES_USER=words -e POSTGRES_PASSWORD=words -p 127.0.0.1:55432:5432 -d postgres:18
docker exec words-game-mvp-db createdb -U words words_game
# Секреты: скопировать .env.example в .env и задать SESSION_PASSWORD (≥32 символов);
# DATABASE_URL=postgresql://words:words@127.0.0.1:55432/words_game, APP_ORIGIN=http://localhost:3000
bun run db:generate
bun run db:dev
bun run dev
```

Необходимые переменные окружения, production-ограничения и команды проверки описаны в [docs/development.md](docs/development.md).
